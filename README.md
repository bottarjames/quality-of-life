# Quality of life

Three small browser sketches by James Evenlind, used in the portfolio Playground.

- **Valet:** preview routing a downloaded filename to a project folder. This sketch does not move files. The actual desktop project is [bottarjames/Valet](https://github.com/bottarjames/Valet).
- **Magic mouse tap:** try tap and hold contacts on three mouse-shaped zones. A browser interaction study, with no hardware connection.
- **Tidloggaren:** name a time block, start, stop, and keep a list in the current tab’s session storage.

## Run locally

Requires Node.js 22 or newer.

```sh
npm install
npm run dev
```

## Check

```sh
npm test
npm run build
```

React, TypeScript, Vite. No backend, API keys, or model calls.
